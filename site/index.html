BEFORE YOU START

Prepare the Raspberry Pi

≈ 10 minutes
✓
Fresh 64-bit Raspberry Pi OS

Use a clean supported image. The fresh installer is not an in-place updater.

✓
Same local network

Connect the Raspberry Pi and this computer to the same Ethernet or Wi-Fi network.

✓
SSH credentials ready

Have the Pi IP address, SSH username and password available.
